Q3. What is Sorting in Excel?
Answer: Sorting in Excel means data ko ascending (A to Z, smallest to largest) ya descending (Z to A, largest to smallest) order mein arrange karna.
Q4. What are the advantages of Sorting in Excel?
Answer:
- Data ko easily arrange kar sakte hain.
- Data ko jaldi search kar sakte hain.
- Highest aur lowest values find kar sakte hain.
- Data ko A to Z ya Z to A order mein arrange kar sakte hain.
- Data ko analyze karna easy ho jata hai.
Q5. What is the use of the IF function in Excel? Give an example.
Answer: IF function kisi condition ko check karta hai. Agar condition TRUE hai, toh ek result deta hai; agar FALSE hai, toh doosra result deta hai.
Example: Agar cell A1 mein marks hain, toh Pass ya Fail check karne ke liye:
=IF(A1>=40,"Pass","Fail")
- Marks 40 ya usse zyada hain → Pass
- Marks 40 se kam hain → Fail
Q6. What is Concatenation in Excel? Give an example.
Answer: Concatenation ka use do ya do se zyada text values ko jodne ke liye hota hai.
Example:
- A1 = Hello
- B1 = World
Formula:
=CONCATENATE(A1," ",B1)
Result: Hello World
Note: Excel mein =CONCAT(A1," ",B1) ya =A1&" "&B1 bhi use kar sakte hain.
Q7. What is the TODAY() function in Excel?
Answer: TODAY() function ka use Excel mein current date dikhane ke liye hota hai.
Formula:
=TODAY()
Result: Aaj ki date show hogi, jaise 14/10/2026.
Note: TODAY() function date ko automatically update karta hai.
Q8. What is the Fill Handle in Excel?
Answer: Fill Handle ek chhota square hota hai jo selected cell ke bottom-right corner mein hota hai. Iska use data, numbers, dates aur formulas ko automatically copy ya fill karne ke liye hota hai.
Example:
1. A1 mein 1 aur A2 mein 2 likho.
2. Dono cells select karo.
3. Fill Handle ko neeche drag karo.
4. Excel automatically 3, 4, 5, 6... fill kar dega.
Advantage: Time save hota hai aur data jaldi fill hota hai.
